# The system of record for documents your agents can use

Docbank stores exact source bytes as authority. Governed processing can add
searchable renditions and embeddings without turning a provider or index into
the record.

- [Install for macOS or Linux](/install.sh)
- [Follow the authority lifecycle](/guide/)
- [Read the operating documentation](/docs/)

## One record, explicit states

1. **Source** — exact retained bytes.
2. **Authorization** — a reviewed processing boundary.
3. **Understanding** — version-bound derivatives.
4. **Retrieval** — evidence behind a source fence.
5. **Recovery** — verified operator-controlled restore.

The [guide](/guide/) follows one document from ingest through proof. The
[operating documentation](/docs/) carries the exact commands and architecture.
